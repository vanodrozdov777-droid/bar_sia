# BAR DESK — Android APK через GitHub Actions

Этот репозиторий содержит веб-версию BAR DESK и Android-оболочку на WebView. APK собирается автоматически в GitHub Actions; Android Studio на компьютере не требуется.

## Что добавить в существующий репозиторий

Распакуйте архив и загрузите в корень существующего репозитория:
- папку `.github/workflows/` (внутри `build-apk.yml`);
- папку `app/`;
- `build.gradle`;
- `settings.gradle`;
- `gradle.properties`;
- `README-APK.md`.

Существующий корневой `index.html` оставьте на месте: workflow копирует его внутрь APK при сборке. Не заменяйте и не удаляйте его.

## Запуск сборки

1. Откройте вкладку **Actions** в GitHub.
2. Выберите workflow **Build BAR DESK APK**.
3. Нажмите **Run workflow** → ещё раз **Run workflow**.
4. Дождитесь зелёной галочки у завершённого запуска.
5. Откройте запуск и найдите блок **Artifacts**.
6. Скачайте **BAR-DESK-APK**. Внутри будет `app-debug.apk`.
7. Передайте APK на Android-телефон и откройте файл для установки. Android может попросить разрешить установку из этого источника.

## Автоматическая сборка

После первого добавления workflow новые изменения `index.html` или Android-файлов в ветке `main` запускают новую сборку автоматически.

## Важно

- Это **debug APK** для установки и проверки, не подписанный релиз для Google Play.
- Приложение открывает локально встроенный `index.html`; для его основного интерфейса интернет не требуется.
- Отметки и настройки сохраняются локально на устройстве. Они не синхронизируются между устройствами.
- Корневой `index.html` остаётся исходником интерфейса и одновременно может публиковаться через GitHub Pages.
