BAR DESK — ПОЛНЫЙ ПРОЕКТ ДЛЯ GITHUB ACTIONS И ANDROID APK

ЗАГРУЗКА:
1. Распакуйте ZIP на компьютере.
2. Откройте репозиторий bar_sia -> Code -> Add file -> Upload files.
3. Перетащите ВСЁ содержимое распакованной папки в КОРЕНЬ репозитория.
   Не загружайте ZIP как один файл и не создавайте дополнительную папку.
4. Включите показ скрытых файлов, если папка .github не отображается.
5. Подтвердите замену файлов, если GitHub её предложит, затем Commit changes.

В корне должны быть index.html, settings.gradle, build.gradle, gradle.properties,
папка app/ и .github/workflows/.

СБОРКА:
1. Откройте Actions.
2. Выберите Build BAR DESK APK.
3. Нажмите Run workflow -> Run workflow, если запуск не начался автоматически.
4. Откройте успешный запуск с зелёной галочкой.
5. Внизу страницы скачайте BAR-DESK-APK из Artifacts.
6. Внутри ZIP находится app-debug.apk.

В ЭТОЙ ВЕРСИИ:
- Android SDK устанавливается явно в workflow перед сборкой.
- Используются Java 17, Gradle 8.9 и Android Gradle Plugin 8.7.3.
- APK проверяется перед публикацией артефакта.
- main.yml заменён на простой workflow-проверку, чтобы не запускать прежний пустой сценарий.

ПРИМЕЧАНИЕ:
Это debug APK для установки и проверки, не подписанный релиз для Google Play.
Реальный результат сборки подтверждается только запуском в GitHub Actions.

ИЗМЕНЕНИЯ В ЭТОЙ ВЕРСИИ:
- index.html заменён на полную версию: 12 вкладок (заявка, лимонады, смузи, милк-шейки, кофе/чай,
  тапиока, авторские, классика, настойки, глинтвейны, матча, полуфабрикаты), 65 рецептур,
  поиск, пересчёт на 1/2/5/10 партий, чек-лист заявки, переключатель темы.
- MainActivity: добавлены отступы под системные панели (Android 15 рисует приложение под ними).
- Workflow: шаг лицензий SDK больше не может сорвать сборку; пересборка запускается и при правке sw.js/manifest.
- index.html в корне и app/src/main/assets/index.html — одинаковые (проверено).
