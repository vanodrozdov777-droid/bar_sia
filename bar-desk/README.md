# Bar Desk — рабочая карта бара

Статическое веб-приложение для GitHub Pages. Не требует сборки, Node.js или базы данных.

## Публикация на GitHub

1. Создайте новый репозиторий на https://github.com/new.
2. Распакуйте архив и загрузите **все три файла и README.md** в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку **main** и папку **/(root)**, нажмите **Save**.
6. Через минуту GitHub Pages покажет ссылку на сайт.

## Возможности

- Поиск по названиям и ингредиентам.
- Разделы меню и технологических карт.
- Масштабирование ингредиентов ×1, ×2, ×5 и ×10.
- Чек-лист закупки с отметками и сбросом.
- Переход из ингредиента-полуфабриката к его рецептуре через ссылку.
- Светлая/тёмная тема.
- Адаптация для телефона и компьютера.
- Локальное сохранение отметок в браузере.
- Кэширование файлов для повторного открытия без сети после первого посещения (при поддержке браузером).

## Важно

Данные сохраняются локально в браузере конкретного устройства. Они не синхронизируются между разными телефонами/компьютерами и браузерами. Очистка данных сайта может сбросить отметки.

Состав рецептур и названия перенесены из исходного файла. Разделы алкогольных коктейлей и алкогольных заготовок не включены; оставлены безалкогольное меню, кофе/чай, матча, тапиока, безалкогольный глинтвейн, полуфабрикаты и заявка.
